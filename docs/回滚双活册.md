# 回滚双活册

> 本册是回滚双活缺陷修复的唯一口径。偏离本册则拒绝并记「双活偏了」。

## 选定路径（2026-11-18 选定，当天不许再换）

**甲路径：回滚事务内停用当前正式并启用目标版。**

同一事务里先 `停用` 当前正式、再 `启用` 目标版，原子切换正式指针；不混用乙路径
（当前正式先入历史快照再切指针、历史版禁止再被选中）。本仓不实现、不调用乙路径。

## 铁律

1. 回滚后正式指针只能有一个（每主题恰一个 `正式+启用`），禁止回滚后成双正式。
2. 禁止回滚丢掉目标必填：目标版 `required_fields` 为空的，拒绝回滚并记「双活偏了」。
3. 回滚与入站两名值班同时抢写须排队（写闸门 `write_gate`），后到者只记一条「回滚入站争用」。
4. 偏离本册（册被篡改/缺失、回滚后指针不唯一、入站撞上双正式）则拒绝并记「双活偏了」。
5. 版本目录、入站列表、详情、对账账册、策略附页只认一正式。

## 落库（指针落库可对）

| 表 | 内容 |
|----|------|
| `rollback_register` | 本册机器可读版：单行，path=甲，decided_on=2026-11-18 |
| `rollback_events` | 回滚链路：subject、from_version、to_version、时间 |
| `contentions` | 争用：kind=回滚入站争用、waiter、holder、时间 |
| `dual_active_deviations` | 双活偏了：kind、detail、时间 |

## 接口

- `POST /api/contracts/rollback` `{subject, target_version}` —— 甲路径原子切换
- `GET /api/contracts` / `GET /api/ingress` / `GET /api/ingress/{id}` / `GET /api/reconcile` —— 均带 `active_formal` 与 `dual_active`
- `GET /api/policy` —— 策略附页：本册、链路、争用、偏离记录
